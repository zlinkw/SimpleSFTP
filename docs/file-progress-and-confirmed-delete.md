# 按路径删除与传输实时进度

0.2.86 的 confirmed_paths 删除使用元数据指纹，不读取权重或其他文件内容。枚举时保留类型、大小、设备、inode、mtime/ctime 及完整子项；符号链接、重解析点、挂载、硬链接、保护目录及越界仍拒绝。执行前复核本次清单和物理直接父目录，删除参数保持 ./直接子名称。普通移动/恢复的 SHA256 内容核验不变。按路径永久删除不写额外审计清单。

清理扫描返回真实 processedFiles；清理请求只建立内存进度上下文，不读取或持久化通用传输回执。传输的停滞检测只提示，手动取消和真实错误仍生效，进度恢复后继续计算；查询控制请求仍有界。

本机批量上传使用一条只读 SSH 查询通道，在传输开始前为本批精确文件建立基线。writtenBytes 按实际远端大小累计并以上传清单大小为上限；writtenFiles 表示已写满的文件数，totalBytes/totalFiles 为本批总量。未变化的旧副本不计入本次传输；这些字段不是成功或内容相同的证据。全部数据只存在内存中，查询通道退出后释放。最终成功仍要求 SSH 正常退出及原有 SHA256 核验。

夹具验证覆盖 64GB 稀疏权重的零内容读取、元数据变化拒绝、部分写入量和空文件计数、旧副本排除、进度停滞后恢复及用户取消。所有可写测试目标均为新建临时夹具，不操作生产目录。
